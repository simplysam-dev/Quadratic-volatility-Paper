# Quadratic-volatility-Paper

## About

This repository contains research and implementation of Quadratic Normal Volatility (QNV) models, including the mathematical derivation and production-grade solver implementation.

## Contents

- **Notebook.ipynb**: Jupyter notebook with initial research and analysis
- **solver/**: Production-grade QNV solver implementation
  - Complete mathematical derivation (main.tex, main.pdf)
  - Production-ready Python solver (qnv_solver.py)
  - Usage examples and test suite
  - Comprehensive diagnostic visualization tools
  - Volatility smile analysis and parameter sensitivity tools

See the [solver/README.md](solver/README.md) for detailed documentation and usage examples of the QNV solver implementation.
